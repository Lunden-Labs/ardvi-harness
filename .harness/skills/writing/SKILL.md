# Writing router

For durable prose, load `writing-skills:writing` with `skill_read` and follow its routing. Load only the dependencies it selects. For ordinary console replies, use `communication` alone.

Preserve code, commands, identifiers, API names, configuration keys, environment variables, URLs, versions, numbers, units, paths, protocol names, error messages, facts, and qualified uncertainty unless the task explicitly changes them. Do not invent facts to improve prose.
